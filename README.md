# Site-de-Advocacia-Jadson-Correia
Website institucional desenvolvido para o escritório Jadson Correia Advocacia. O projeto apresenta as áreas de atuação, formação profissional, conteúdos jurídicos e canais de contato, com design responsivo e navegação adaptada para dispositivos móveis. Desenvolvido com HTML5, CSS3 e JavaScript.
